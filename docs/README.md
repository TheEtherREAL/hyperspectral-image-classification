# 项目文档导航

`docs/` 只保留当前开发与课程交付直接相关的文档。已被合并、替代或只用于追溯的早期材料保留在本地归档，不进入精简的公共仓库。

## 首先阅读

1. `solution_report/高光谱智能解译大作业实施报告.md`：当前唯一核心解题/实施报告，说明阶段成果、验收证据和作业符合度；
2. `paper/高光谱图像分类研究论文.md`：研究论文草稿，当前完成方法和数据阶段结果；
3. `TASK_BOARD.md`：全部阶段状态和下一步任务；
4. `EXPERIMENT_PROTOCOL.md`：正式训练、评价和公平比较红线。
