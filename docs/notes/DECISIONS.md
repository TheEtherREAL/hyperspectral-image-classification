## D006：固定 Pavia University 的两套分层划分协议

- 日期：2026-08-13
- 决策：统一使用 `seed=345`。先按类别分层生成 30% 候选训练池与 70% 测试集；`paper30` 将候选池全部用于训练，`fair24_6_70` 再把候选池按 80%/20% 分层拆为训练集和验证集。
- 结果：`paper30` 为 12,832/0/29,944，`fair24_6_70` 为 10,265/2,567/29,944（train/validation/test）。两套协议共享完全相同的测试集，且 fair 的 train+validation 等于 paper30 的 train。
- 原因：`paper30` 保留论文兼容的 30%/70% 复现口径；`fair24_6_70` 在不改变测试集的前提下提供独立验证集，供调参与统一模型比较使用。两套协议的结果不得混在同一公平比较表中。

## D007：固定划分的样本与文件契约

- 日期：2026-08-13
- 决策：划分样本保存原标签图中的零基 `(row, column)` 二维坐标和原始类别编号 1–9，背景 0 不进入划分；每套协议同时保存压缩 `.npz`、完整 `.json` 元数据和逐类 `.csv` 统计。
- 元数据：记录源文件 SHA-256、MATLAB 变量名、数据形状、类别名称、seed、目标与实际比例、分层步骤、坐标/标签约定和软件版本。
- 验收：自动检查三组无交集、覆盖全部 42,776 个有标签像元、每个非空 split 含全部 9 类、同 seed 可复现，并核对两套协议之间的共享测试集关系。
- 分步复核：固定划分与两协议关系的检查最初由独立 Notebook 提供；D013 后已合并到唯一 Notebook，D014 后中文命名为 `notebooks/高光谱数据预处理主流程.ipynb`。
- 原因：后续所有模型可以直接复用同一逐样本索引，并能从原始文件和协议参数追溯、复核划分来源。

## D008：数据预处理采用配置驱动的统一可插拔管线

- 日期：2026-08-13
- 决策：所有路线共用 `src/datasets/高光谱预处理.py`，通过 YAML 组合光谱处理和空间表示。D018 后正式支持 `none/PCA/LDA × pixel/patch`；波段选择、LBP 和 Gabor 保留显式接口，未实现时必须报错。

- 原因：减少重复代码和路线间的隐性口径差异，使后续多方法、多配置和多随机种子实验能够公平对比。

## D009：统计预处理严格限定为训练中心像元拟合

- 日期：2026-08-13
- 决策：逐波段标准化与 PCA 只使用固定训练坐标处的光谱拟合，验证、测试和背景像元只调用 `transform`。PCA 基线为 15 维、`whiten=false`；完整影像使用训练参数分块变换。
- 状态：分别冻结 `paper30` 和 `fair24_6_70` 的标准化/PCA 参数，不跨协议复用；状态记录源文件与 split 哈希、配置指纹、解释方差和软件版本。
- 结果：`paper30` 与 `fair24_6_70` 的 PCA15 累计解释方差比分别为 0.9992432505 和 0.9992470915。该指标表示方差保留程度，不是分类准确率。
- 原因：避免测试信息泄漏，同时保证每个实验结果能够追溯到唯一的数据、划分和预处理状态。

## D010：阶段 2 使用临时网络验收数据管线

- 日期：2026-08-13
- 决策：使用现已在原开发机器本地归档的极小临时网络，在 `fair24_6_70` 已冻结预处理状态上完成短批次检查和完整 1 epoch GPU 检查；临时网络不进入公共仓库的 `src/models/`，不保存 checkpoint，也不作为 HybridSN 或其他分类模型。
- 范围：验收 DataLoader、真实 patch、GPU 搬运、前向传播、交叉熵、反向传播、参数更新和验证只读过程。测试集只记录可用样本数，禁止计算测试集损失或分类指标。
- 证据：完整运行遍历 10,265 个训练样本（161 批）和 2,567 个验证样本（41 批），训练参数确实变化，验证阶段参数保持不变；日志标记 `formal_experiment=false`、`paper_result_eligible=false` 与 `test_set_evaluated=false`。
- 原因：在正式定义 HybridSN 之前先隔离并排除数据维度、标签、边界 patch、最后一个不满批次和 GPU 反传问题，同时防止把管线诊断数值误写成论文性能结果。

## D018：LDA 采用 sklearn SVD 实现并由 YAML 一行切换

- 日期：2026-08-13
- 决策：在统一 `HSIPreprocessingPipeline` 中实现 `LinearDiscriminantAnalysis(solver="svd")`；LDA 仅使用固定训练中心像元的标准化光谱和训练标签拟合，验证/测试/背景只执行 `transform`。Pavia University 默认 `n_components=8`，并强制不超过九类对应的 `C-1=8`。
- 配置：每份新版 YAML 同时保存 `pca:` 与 `lda:` 方法专属参数块。只修改 `spectral_preprocessing.reducer: pca` 为 `lda`，即可从 PCA15 切换到 LDA8，而 split、seed、空间表示及 DataLoader 参数不变。
- 状态：冻结并独立验证 fair 的 LDA8 pixel/patch25 和 paper30 的 LDA8 patch25；状态保存 solver、训练类别、均值、判别缩放矩阵、解释比、配置指纹和拟合范围。
- 验收：LDA 变换与本地 scikit-learn 1.9.0 官方估计器数值一致；改变验证/测试光谱不会影响拟合参数；保存重载与重新构建一致；PCA 与 LDA 版本的唯一 Notebook 均能完整执行。
- 原因：满足教师 PCA/LDA 学习要求，并让后续传统分类器或深度对照路线在共享样本身份与无泄漏边界下只通过配置切换降维方法。
