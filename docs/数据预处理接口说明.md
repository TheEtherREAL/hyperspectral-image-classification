# 高光谱数据预处理管线接口说明

## 1. 作用域

正式实现位于：

```text
src/datasets/高光谱预处理.py
```

该文件负责原始数据与固定划分读取、标准化、光谱变换、空间表示、传统特征矩阵、PyTorch Dataset/DataLoader 和预处理状态管理。

该文件不负责：

- CNN、HybridSN、SVM 或 XGBoost 模型定义；
- 损失函数、优化器与训练循环；
- OA、AA、Kappa 等评价；
- 重新生成数据划分。

## 2. 固定数据契约

所有路线共享：

```text
sample_index：有标签样本数组中的稳定索引
coordinate：原标签图零基 (row, column)
raw_label：原始类别 1..C
label：模型类别 0..C-1
split：train / validation / test
```

任何新增路线不得自行重排或重新划分测试集。

## 3. 快速运行

### 3.1 推荐分步 Notebook

```text

```

该 Notebook 与命令行主程序共享七个中英双语接口，适合逐格查看类别构成、划分空间图、训练光谱统计、PCA/LDA 解释比与散点、Dataset、代表性 patch、DataLoader 和 batch 构成；默认加载公平比较的 PCA15 + patch25 路线，也可只换配置运行 LDA8，不写出正式文件。

绘图函数集中在 `src/visualization/预处理分析.py`。split 数量和空间位置可显示全部冻结划分；光谱、PCA 散点、patch 与 batch 内容只使用训练集。

```text

```

## 4. 配置结构

```yaml
dataset:
  name: pavia_university
  split_protocol: fair24_6_70
  split_seed: 1442

spectral_preprocessing:
  standardization: standard
  reducer: pca  # 只改为 lda 即切换方法
  pca:
    n_components: 15
    whiten: false
  lda:
    n_components: 8

spatial_preprocessing:
  representation: patch
  patch_size: 25
  padding_mode: constant
  padding_value: 0.0

output:
  dtype: float32
```

### 4.1 当前支持

- `standardization`: `standard`、`none`；
- `reducer`: `pca`、`lda`、`none`；
- `representation`: `patch`、`pixel`；
- `padding_mode`: `constant`、`reflect`、`edge`。

### 4.2 已预留但未实现

- reducer：`band_selection`；
- representation：`lbp`、`gabor`。

选择未实现值会抛出 `NotImplementedError`，用于防止实验误标。Pavia 有 9 类，LDA 的 `n_components` 必须在 1–8 之间；当前固定采用 sklearn 推荐的 `solver="svd"`。

### 4.3 sklearn 官方实现对应关系

- PCA 使用 `sklearn.decomposition.PCA` 的 `fit(X_train)` 语义；项目先以训练集逐波段标准化，再固定 `svd_solver="full"`，并按 YAML 决定是否白化。
- LDA 使用 `sklearn.discriminant_analysis.LinearDiscriminantAnalysis(n_components=..., solver="svd")` 的 `fit(X_train, y_train)` 与 `transform(X)` 语义；只支持官方推荐的 SVD 路线，避免在 YAML 中出现当前实验不需要的 solver 分支。
- sklearn 官方 PCA 与 LDA 示例同样将 PCA 作为无监督变换、LDA 作为带标签的监督变换。项目在此基础上增加固定 split、训练集拟合边界、状态序列化和 PyTorch 数据接口。

官方参考：[PCA API](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)、[LDA API](https://scikit-learn.org/stable/modules/generated/sklearn.discriminant_analysis.LinearDiscriminantAnalysis.html)、[PCA vs LDA 示例](https://scikit-learn.org/stable/auto_examples/decomposition/plot_pca_vs_lda.html)。

## 5. Python API

```python
from pathlib import Path
import yaml

from src.datasets.高光谱预处理 import (
    HSIPreprocessingPipeline,
    PreprocessingConfig,
    load_hsi_data,
)

project_root = Path("G:/高光谱智能图像解译/实验交付")
values = yaml.safe_load(
    (project_root / "configs/数据预处理/Pavia数据预处理.yaml")
    .read_text(encoding="utf-8")
)
config = PreprocessingConfig.from_mapping(values)
data = load_hsi_data(project_root, config)
pipeline = HSIPreprocessingPipeline(config).fit(data)
```

### 5.1 PyTorch 出口

```python
loaders = pipeline.build_torch_loaders(
    data,
    batch_size=256,
    loader_seed=1442,
    num_workers=0,
    pin_memory=True,
)

batch = next(iter(loaders["train"]))
```

patch 路线的 batch：

```text
batch["input"]        float32  (N, 1, B, H, W)
batch["label"]        int64    (N,)      0..C-1
batch["raw_label"]    int64    (N,)      1..C
batch["coordinate"]   int64    (N, 2)
batch["sample_index"] int64    (N,)
```

`paper30` 的 `loaders["validation"]` 为 `None`。

### 5.2 传统分类器出口

只有 `representation: pixel` 可直接调用：

```python
splits = pipeline.build_feature_splits(data)
x_train = splits["train"].x
y_train = splits["train"].y
```

每个 `FeatureSplit` 同时保存 `raw_labels`、`coordinates` 与 `sample_indices`。patch 不自动展平；若后续需要 CNN 特征 + SVM，应建立明确的“深度特征提取器”路线，而不是在数据层随意展平。

## 6. 拟合与变换边界

允许进入统计拟合的数据只有：

```python
train_spectra = cube[train_rows, train_columns, :]
```

标准化、PCA、LDA 和未来的监督波段选择都必须遵循：

```text
fit(train only)
transform(train / validation / test / full cube)
```

禁止：

- 在完整立方体上调用 `fit`；
- 使用验证集或测试集标签拟合变换；
- 为不同模型重新生成测试集；
- 将 `paper30` 预处理状态用于 `fair24_6_70`。

## 7. 路线兼容性

| 光谱处理 | 表示 | 后续模型 | 状态 |
|---|---|---|---|
| none | pixel | SVM/XGBoost/MLP | 已支持 |
| PCA | pixel | SVM/XGBoost/MLP | 已支持 |
| PCA | patch | HybridSN/3D-CNN | 已支持 |
| none | patch | 3D-CNN | 接口支持，但计算量较大，需显式实验 |
| LDA | pixel | SVM/XGBoost | 已支持，最大维数 C-1 |
| LDA | patch | CNN 对照路线 | 数据接口已支持；正式模型兼容性需单独实验 |
| band selection | pixel/patch | 传统/深度模型 | 待实现 |
| PCA + LBP/Gabor | feature vector | SVM/XGBoost | 待实现 |
| LBP histogram | HybridSN | 不支持，表示不兼容 |

## 8. 状态文件

`preprocessing_state.npz` 保存：

- 标准化开关、均值、缩放因子和拟合样本数；
- reducer 名称；
- PCA 分量、PCA 均值、解释方差、解释方差比和奇异值；
- LDA 的 SVD solver、类别、训练均值、判别缩放矩阵和判别解释比；
- schema 版本和配置指纹。

`metadata.json` 保存：

- 数据集与类别；
- 原始数据 SHA-256；
- split 文件、协议、seed、SHA-256 与样本数；
- 拟合范围；
- 标准化、PCA/LDA 与 patch 配置；
- 标签契约；
- Python、NumPy、scikit-learn 与 PyTorch 版本。

完整立方体和全部 patch 不写入状态文件。加载状态后调用：

```python
loaded = HSIPreprocessingPipeline.load_state(state_path, metadata_path)
loaded.attach_transformed_cube(data.cube)
```

即可恢复相同的变换结果。

## 9. 扩展新方法的规则

### 9.1 新增光谱 reducer

新 reducer 至少实现：

```text
fit(spectra, labels=None)
transform(spectra)
state()
from_state(...)
n_output_features
```

并在配置校验、构建函数、保存/加载和测试中注册。监督方法必须测试“改变非训练标签不会影响参数”。

### 9.2 新增空间表示

LBP/Gabor 应作为特征提取器输出可追溯特征向量，并明确：

- 输入使用哪些 PCA 分量或波段；
- 邻域大小；
- 参数集合；
- 特征维数；
- 是否需要训练拟合；
- 如何与光谱特征拼接。

不得把特征算法直接写进 SVM 或 XGBoost 训练脚本。

## 10. 数据管线冒烟验收

阶段 2 使用独立的极小临时网络验证真实数据出口。该网络只用于检查数据和训练接口是否连通，不属于正式模型，不保存 checkpoint，也不产生可写入论文结果表的分类指标。

历史小网络实现在原开发机器本地归档，不属于公共仓库或日常入口，也不需要在模型开发前重复运行。

验收必须同时满足：

- 使用已保存的 `fair24_6_70__seed1442__standard_pca15_patch25` 状态，不重新拟合标准化或 PCA；
- 训练、验证样本数分别为 10,265 和 2,567；
- 梯度为有限非零值，训练阶段参数发生变化；
- 验证阶段不发生参数更新；
- 日志明确记录 `formal_experiment=false`、`paper_result_eligible=false` 和 `test_set_evaluated=false`。

2026-08-13 的完整验收日志保存在原开发机器本地，上述条件全部通过。日志中的 loss 与 diagnostic accuracy 仅用于程序诊断，不得作为论文模型性能。
