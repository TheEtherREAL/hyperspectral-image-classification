## 摘要

高光谱图像同时包含丰富的光谱信息与空间信息，但其波段维数高、类别分布不均衡，并且数据划分与统计变换方式容易引入测试信息泄漏。为建立可复现且可公平比较的课程实验基座，本文以 Pavia University 数据集为首个研究对象，设计了一套配置驱动的高光谱数据处理与实验组织框架。该框架首先固定两种分层随机划分协议：用于 HybridSN 论文兼容复现的 `paper30` 协议，以及用于超参数选择和多模型公平比较的 `fair24_6_70` 协议；随后仅利用训练中心像元拟合逐波段标准化与主成分分析（PCA），并仅利用训练光谱和训练标签拟合线性判别分析（LDA），分别将 103 个原始波段映射为 15 个主成分或 8 个判别分量；最后通过统一接口输出中心像元特征矩阵或 25×25 光谱—空间邻域块。当前阶段已完成固定划分、无泄漏标准化、PCA/LDA、动态邻域提取、PyTorch Dataset/DataLoader、状态序列化、自动测试及完整 1 epoch GPU 数据链路验收。在 `fair24_6_70` 训练子集上拟合的 PCA15 累计解释方差比为 99.9247%；LDA8 覆盖九分类问题允许的完整八维判别子空间。后续实验将先使用 `paper30` 复现 HybridSN 基线，再在 `fair24_6_70` 上开展不同光谱处理、空间表示和分类器组合的多随机种子比较与消融分析。

**关键词：** 高光谱图像分类；HybridSN；主成分分析；光谱—空间特征；数据泄漏；可复现实验

## 1 引言

高光谱遥感影像在连续窄波段上记录地物反射响应，使单个像元可由一条高维光谱向量描述。相比普通 RGB 图像，高光谱数据能够区分颜色相近但材料组成不同的地物，已广泛应用于农业监测、城市地物识别和环境分析。然而，高维光谱也带来波段冗余、样本不均衡、空间上下文利用不足和计算开销较大等问题。

传统高光谱分类通常将降维、人工空间特征和分类器分开设计。例如，PCA 或 LDA 用于降低光谱维数，LBP 或 Gabor 特征用于描述局部纹理，SVM 或梯度提升树用于完成分类。深度学习方法则通过卷积网络直接学习特征。Roy 等提出的 HybridSN 使用连续 3D 卷积联合提取光谱—空间特征，再以 2D 卷积学习更高层空间表示，在控制三维卷积复杂度的同时保留联合建模能力 [1]。

教师课程任务依次要求完成 PyTorch 环境与高光谱数据处理、HybridSN 分类复现、HybridSN 改进以及其他模型的多数据集比较。若不同路线分别编写数据代码，容易出现划分不一致、标签错位或测试集参与拟合等问题。因此，本文首先建立统一的数据身份和预处理接口，使不同光谱变换、空间表示及分类器共享同一坐标、标签和测试集。需要说明的是，本文当前版本完成的是模型实验前的数据基座，而不是完整分类任务；HybridSN 及后续改进模型的正式结果将在下一阶段补充。本文当前工作的主要贡献如下：

1. 固定并验证 Pavia University 的论文兼容划分与公平比较划分，保存逐样本二维坐标、原始标签和完整元数据；
2. 实现只在训练中心像元上拟合的标准化与 PCA，以及只使用训练光谱和训练标签拟合的 LDA，阻断验证集和测试集信息泄漏；
3. 设计 `none/PCA/LDA × pixel/patch` 的可配置数据接口，使 PCA15 与 LDA8 可通过 YAML 的 `reducer` 字段一行切换；
4. 为传统分类器和 PyTorch 深度模型提供共享 sample ID、坐标和标签契约，为后续多路线、多随机种子比较奠定基础。

## 2 相关方法

### 2.1 光谱降维与特征选择

PCA 是一种无监督线性降维方法，通过寻找最大化样本方差的正交方向，将原始波段映射为较少的主成分 [2]。它不直接利用类别标签，适合降低光谱冗余，但最大方差方向未必等同于最具类别判别力的方向。LDA 则利用类别标签，使类间散度相对类内散度尽可能大 [3]；对于含 (C) 个类别的数据，其输出维数不超过 (C-1)，因此 Pavia University 的 LDA 输出至多为 8 维。波段选择不构造线性组合，而是保留部分真实波段，通常具有更强的物理可解释性。

### 2.2 空间特征表示

仅使用中心像元光谱向量会忽略邻域纹理和形状。LBP 通过比较邻域灰度关系编码局部纹理 [4]；Gabor 滤波器通过不同尺度与方向的带通响应描述空间频率特征 [5]。另一类方法直接提取固定尺寸邻域块，并由卷积神经网络学习空间结构。本文首个深度基线采用 25×25 邻域，该尺寸与 HybridSN 在 Pavia University 上使用的输入空间范围一致 [1]。

### 2.3 传统分类器与深度模型

SVM 通过最大间隔决策边界处理高维小样本分类，已广泛用于高光谱遥感 [6]。XGBoost 通过加法树模型与正则化目标函数实现可扩展梯度提升 [7]。HybridSN 则将 3D CNN 与 2D CNN 串联：前者联合建模光谱与空间信息，后者进一步抽象空间特征，最后由全连接分类头输出类别 logits [1]。对于当前单标签九分类任务，训练采用交叉熵损失；模型内部不必显式添加 Softmax，推理阶段再将 logits 转换为概率。

## 3 数据与方法

### 3.1 数据集与标签

Pavia University 数据立方体尺寸为 610×340×103，分别表示空间高度、空间宽度和光谱波段数。标签图尺寸为 610×340，其中 0 为背景或未标注像元，1–9 分别对应 Asphalt、Meadows、Gravel、Trees、Painted metal sheets、Bare Soil、Bitumen、Self-Blocking Bricks 和 Shadows。共有 42,776 个有标签像元参与训练、验证和测试。

### 3.2 固定数据划分

本文使用 `seed=345` 按类别标签分层随机划分。首先将全部有标签像元划分为 30% 候选训练池和 70% 公共测试集，然后构造两套协议：

- `paper30`：12,832 个训练样本、无验证样本、29,944 个测试样本，用于尽量对齐原论文的 30%/70% 训练测试设置 [1]；
- `fair24_6_70`：将候选训练池再次按类别分层为 10,265 个训练样本和 2,567 个验证样本，同时保持相同的 29,944 个测试样本，用于调参与公平比较。

两套协议共享完全相同的测试集，且 `fair24_6_70` 的训练集与验证集合并后严格等于 `paper30` 的训练集。每个样本保存零基二维坐标 $(r,c)$、原始标签 $y\in\{1,\ldots,9\}$ 和 split 索引。测试集仅用于最终评价，不参与超参数或最佳轮次选择。

### 3.3 训练集专用标准化

设训练中心像元的光谱矩阵为 $X_{tr}\in\mathbb{R}^{N_{tr}\times D}$，其中 $D=103$。对第 $d$ 个波段，仅使用训练样本计算均值与总体标准差：

\[
\mu_d=\frac{1}{N_{tr}}\sum_{i=1}^{N_{tr}}x_{id},\qquad
\sigma_d=\sqrt{\frac{1}{N_{tr}}\sum_{i=1}^{N_{tr}}(x_{id}-\mu_d)^2}.
\]

任意样本按

\[
\tilde{x}_{id}=\frac{x_{id}-\mu_d}{\sigma_d}
\]

进行变换。若某波段训练标准差为 0，则将缩放因子置为 1。验证集、测试集和未标注区域只使用训练集得到的 (mu_d) 与 (sigma_d)，不重新估计参数。

### 3.4 PCA 光谱降维

在标准化后的训练中心像元上拟合 PCA。设训练协方差矩阵的前 $B$ 个特征向量构成投影矩阵 $W_B\in\mathbb{R}^{D\times B}$，则降维表示为

\[
Z=(\tilde{X}-m_{PCA})W_B,
\]

其中本文首个基线取 $B=15$，`whiten=false`。拟合结束后，将相同投影分块应用于完整影像，得到 610×340×15 的变换后数据立方体。`fair24_6_70` 训练子集上前 15 个主成分累计解释方差比为 0.999247。该数值仅描述训练数据方差保留程度，不代表分类准确率。

### 3.5 LDA 监督光谱降维

LDA 使用类别信息构造判别子空间。设第 $k$ 类训练样本均值为 $\mu_k$，全局训练均值为 $\mu$，则类内散度与类间散度可分别写为

\[
S_W=\sum_{k=1}^{C}\sum_{x_i\in k}(x_i-\mu_k)(x_i-\mu_k)^T,
\qquad
S_B=\sum_{k=1}^{C}n_k(\mu_k-\mu)(\mu_k-\mu)^T.
\]

LDA 寻找使类间差异相对于类内差异增大的投影方向。本文依照 scikit-learn 官方接口采用 `LinearDiscriminantAnalysis(solver="svd")` [9]；该求解器不显式计算协方差矩阵，适用于波段维数较高的输入。实现调用 `fit(\tilde{X}_{tr},y_{tr})`，其中光谱与标签均严格来自训练 split；随后仅调用 `transform` 处理验证、测试、背景和完整影像。由于 LDA 输出维数满足 $B\leq\min(D,C-1)$，Pavia University 的 $C=9$，故默认采用 $B=8$，输出 610×340×8 数据立方体。状态文件保存训练类别、训练均值、判别缩放矩阵与解释比，使推理阶段无需再次读取标签或重新拟合。

### 3.6 统一空间表示与模型输入

本文定义两类已实现输出：

1. `pixel`：在固定中心坐标处取得 $B$ 维光谱向量，构成 $N\times B$ 特征矩阵，供 SVM、XGBoost 或 MLP 使用；
2. `patch`：对完整变换后立方体进行边界填充，并以固定坐标为中心动态提取 $25\times25\times B$ 邻域。对 HybridSN，PyTorch 单样本张量整理为 $1\times B\times25\times25$，batch 形状为 $N_b\times1\times B\times25\times25$。

patch 不预先全部物化到磁盘，以避免重复存储。固定划分依据中心像元；邻域中不使用其他像元的类别标签。由于本文采用逐像元随机划分，相邻中心像元的 patch 可能重叠，此限制将在最终结果讨论中明确说明，并可在后续加入空间块划分作为严格泛化对照。

### 3.7 配置驱动的多路线框架

数据处理框架将“光谱处理—空间表示—模型”分离。当前实现的光谱处理为 `none`、`PCA` 和 `LDA`，空间表示为 `pixel` 和 `patch`；波段选择、LBP 与 Gabor 仍为后续扩展。YAML 同时保留 `pca:` 与 `lda:` 方法专属参数块，只需将 `reducer: pca` 改为 `reducer: lda`，即可由 PCA15 切换为 LDA8，而数据协议、随机种子、空间表示和 DataLoader 参数均保持不变。传统出口返回特征、零基模型标签、原标签、坐标和 sample ID；PyTorch 出口返回字典形式的输入张量及相同身份字段。不同方法通过独立配置指纹与冻结目录管理，由此可以共享固定测试样本并将预测映射回原图，同时避免统计预处理参数混用。

### 3.8 预处理状态与可追溯性

每个已拟合预处理状态记录数据集、split 协议、split seed、训练样本数、原始文件与 split 文件 SHA-256、标准化参数、PCA 分量及解释方差或 LDA 判别投影状态、patch 配置、软件版本和配置指纹。状态文件不包含第三方模型权重，也不复制完整 patch。不同 split 或不同配置产生不同目录，默认拒绝覆盖已有正式产物。

## 4 实验设计

### 4.1 论文兼容复现

首先在 `paper30` 上复现 HybridSN。预处理采用训练集专用标准化、PCA 15 维和 25×25 patch；模型训练轮数、batch size、优化器等尽量遵循原论文。原论文报告使用 Adam、batch size 256、100 epochs、无 batch normalization 与数据增强，并对 Pavia University 使用 25×25×15 输入 [1]。由于 `paper30` 没有独立验证集，本实验不得利用测试集选择最佳 epoch，而应采用预先固定的训练策略。

### 4.2 公平比较与调参

随后在 `fair24_6_70` 上进行模型选择。所有候选方法共享相同 train/validation/test；训练集用于拟合预处理和模型参数，验证集用于选择超参数与 checkpoint，测试集仅在配置冻结后评价。计划比较的路线包括：

- PCA15 + patch25 + HybridSN；
- PCA15 + pixel + SVM/XGBoost；
- 无降维 + pixel + SVM/XGBoost；
- LDA8 + pixel + SVM/XGBoost（数据路线已实现，分类实验待阶段 3）；
- 波段选择 + pixel/patch + 传统或深度模型（待实现）；
- PCA + LBP/Gabor + SVM/XGBoost（待实现）。

### 4.3 多随机种子与评价指标

数据划分 seed 固定为 345，不随模型训练改变。每种正式模型配置至少运行 3 个训练随机种子，报告均值和标准差。评价指标包括 Overall Accuracy（OA）、Average Accuracy（AA）、Cohen's Kappa、每类准确率和混淆矩阵；横向比较同时报告参数量、训练时间和推理时间。不同 split 协议下的结果不进入同一公平比较表。

## 5 当前结果与待完成实验

当前仅报告数据与预处理验收结果，不报告分类精度：

- Pavia University 有标签像元 42,776 个，两套固定划分均通过无交集、全覆盖、类别覆盖和同 seed 复现检查；
- `fair24_6_70` 上标准化、PCA 与 LDA 的拟合样本数为 10,265；LDA 只额外使用训练标签，验证/测试样本及标签均未参与拟合；
- PCA 输出数据立方体尺寸为 610×340×15，累计解释方差比为 99.9247%；
- LDA 输出数据立方体尺寸为 610×340×8；保存状态重载与重新拟合结果一致，且变换数值与 scikit-learn SVD-LDA 一致；
- patch DataLoader 的批输入形状已验证为 `batch_size×1×15×25×25`；
- 临时小网络已在 RTX 5070 上完成 `fair24_6_70` 全部 10,265 个训练样本与 2,567 个验证样本的 1 epoch 链路验收，测试集未用于该检查；
- 当前核心自动测试共 48 项通过，覆盖统一 YAML 的七种历史路线选择、归档完整性、固定划分、跨协议关系、PCA/LDA 无泄漏预处理、状态重载、数据接口、主流程、复现性和描述性统计接口；完整 GPU 冒烟证据另以冻结 JSON 日志保留。

上述临时网络只用于验证批次、GPU、反向传播和验证只读过程，其诊断损失与准确率不属于论文分类结果。HybridSN 的 OA、AA、Kappa、逐类准确率、训练曲线、混淆矩阵和分类图均待正式实验产生。任何外部论文数值或 archive 中的 Keras 预训练结果均不得作为本文实验结果。

## 6 结论

本文当前完成了面向复现与多路线比较的高光谱数据处理基座。通过冻结逐样本划分、限制统计变换的拟合范围、统一样本身份并分离数据表示与模型定义，后续可以在不改变测试集的前提下扩展传统方法、深度模型和消融路线。该阶段实现符合课程作业的数据处理方向，但尚未形成 HybridSN 分类结果，不能替代完整基础档验收。下一阶段将在独立模型文件中复现 HybridSN 结构，随后在 `paper30` 上开展论文兼容实验，并在 `fair24_6_70` 上进行调参与多模型公平比较。
