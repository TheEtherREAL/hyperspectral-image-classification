## 1. 作业目标与当前结论

教师给出的任务主线是：学习 PyTorch 与高光谱数据处理，使用 PCA、LDA 等方法理解降维，复现 HybridSN 完成分类；进一步改进 HybridSN，并复现其他论文模型，在 Pavia University、Indian Pines、Houston 等数据集上比较结果。

本项目当前已经完成统一数据基座、HybridSN 结构复现和首个正式 baseline。主要成果是：可用的 GPU PyTorch 环境、经过审计的高光谱数据、两套可复现的 Pavia University 固定划分、只在训练集拟合的标准化与 PCA15、只使用训练光谱和训练标签拟合的 LDA8、pixel/patch 两种数据表示、PyTorch Dataset/DataLoader、模型就绪数据产物、原论文 HybridSN 模型定义、可恢复训练与推理 CLI、统一评价与可视化接口、两本分工明确的 Notebook 和自动化测试。

统一种子后的正式运行采用 split/训练/DataLoader seed=1442、Adam 1e-3、batch 256 和固定 100 epochs，不使用 test 选择 checkpoint。最终 OA=99.9532%、AA=99.8790%、Kappa=0.999380，并输出 checkpoint、日志、性能、混淆矩阵、逐类精度、学习曲线和分类图。需要同时指出：随机像元划分配合 25×25 patch 产生强空间重叠，100% 测试 patch 含训练中心像元且 100% 含同类训练中心像元；因此该高分只作为课程/论文兼容 baseline，不能替代严格跨区域泛化验证。整项作业的模型改进、多种子和多数据集部分仍未完成。

### 2.2 数据读取与审计

当前已经审计 Pavia University、Indian Pines corrected 和 Salinas corrected，核对了 `.mat` 文件、变量名、数据形状、标签范围、标注像元数与文件哈希。教师要求中的 Houston 数据当前尚未取得，因此不能宣称已经完成三数据集实验。

本阶段的首个闭环使用 Pavia University：数据立方体尺寸为 `610×340×103`，标签图为 `610×340`，包含 9 类、42,776 个有标签像元。标签 0 为背景，不进入训练、验证或测试统计。

### 2.3 固定数据划分

项目统一使用 `seed=1442` 按类别分层建立两套协议：

| 协议 | 训练集 | 验证集 | 测试集 | 用途 |
|---|---:|---:|---:|---|
| `paper30` | 12,832 | 0 | 29,944 | 对齐 HybridSN 论文 30%/70% 口径 |
| `fair24_6_70` | 10,265 | 2,567 | 29,944 | 验证集调参与公平比较 |

两套协议共享同一测试集；`fair24_6_70` 的训练集与验证集合并后严格等于 `paper30` 的训练集。每个样本保存零基二维坐标、原始标签、模型标签、split 身份和稳定 sample index。

自动检查已经验证：

- train、validation、test 互不重叠；
- 覆盖全部 42,776 个有标签像元；
- 每个非空 split 都包含全部 9 类；
- 相同种子能够重建相同结果；
- 坐标、标签图和类别编号一致；
- 两套协议之间的公共测试集关系成立。

### 2.4 无泄漏标准化、PCA 与 LDA

标准化与 PCA 都只使用固定训练中心像元拟合；LDA 还只读取对应训练标签。验证集、测试集和背景像元仅调用训练参数进行变换，不参与均值、标准差、PCA 投影或 LDA 判别方向的估计。

当前 HybridSN 数据基线使用：

```text
103 个原始波段
→ 训练集逐波段标准化
→ 训练集拟合 PCA
→ 15 个主成分
→ 610×340×15 变换后立方体
```

`fair24_6_70` 的 PCA15 累计解释方差比为 `0.9992360427`，即约 99.9236%。该数值只表示训练数据方差保留程度，不是分类准确率。

LDA 路线严格采用 scikit-learn `LinearDiscriminantAnalysis(solver="svd")`。它利用类别标签寻找更有判别力的线性投影；Pavia University 有 9 类，因此输出维数满足 `n_components≤C-1=8`。当前 LDA8 基准产生 `610×340×8` 立方体。8 个判别方向的解释比之和为 1，表示已包含完整 LDA 判别子空间，同样不代表分类准确率。

### 2.5 Pixel、Patch 与 PyTorch 接口

管线提供两种模型输入：

- `pixel`：单个中心像元的光谱向量，可供后续 SVM、XGBoost 或 MLP 使用；
- `patch`：以标注坐标为中心动态提取 `25×25×15` 邻域，可供 HybridSN、3D-CNN 等模型使用。

HybridSN 路线的张量契约为：

```text
单样本 input: 1×15×25×25
批次 input:   N×1×15×25×25
label:        0–8 的 int64
raw_label:    1–9
coordinate:   N×2
sample_index: N
```

patch 按需生成，不把全部邻域重复写入磁盘。边界 patch 使用可配置 padding，同时保留中心坐标和样本身份，便于将预测映射回原标签图。

### 2.6 配置、可视化与工程接口

数据路线通过 YAML 配置，当前提供论文复现、公平比较、PCA/LDA 单像元或邻域和原始 103 波段单像元配置。每份新版 YAML 同时保存 `pca:` 与 `lda:` 参数块，只修改 `reducer: pca` 为 `reducer: lda` 即从 PCA15 切换到 LDA8。修改 batch size、loader seed 或 worker 不需要重建降维状态；切换方法或修改分量数、patch、标准化或表示方式时，必须使用具有独立路线名与配置指纹的冻结状态。

项目的数据与模型流程分为同一路径下的两本 Notebook：

1. `notebooks/高光谱数据预处理主流程.ipynb` 展示类别构成、split 空间位置、训练光谱、PCA/LDA 解释比、训练集二维散点、代表性 patch 和 batch 构成，并将 `paper30 + seed1442 + standard + PCA15 + patch25` 的模型就绪数据保存为 `model_ready_dataset.npz`。产物只保存一个变换后立方体以及坐标、标签和固定 split 索引，不重复物化全部 patch；若同指纹产物已经存在则验证并复用，不覆盖固定划分或冻结 PCA 状态。
2. `notebooks/HybridSN模型结构学习.ipynb` 只读加载上述产物，动态生成 patch，并依次展示模型源码、逐层 shape、参数量、损失、优化器、训练/验证函数、曲线和最终评价接口。正式训练与测试开关默认关闭。

为避免测试集窥视，数据特征可视化只使用训练集；`paper30` 没有验证集，因此正式论文复现将采用预先固定的最终 epoch，而不允许依据测试集选择 checkpoint。

### 2.7 HybridSN 原论文结构复现

结构核对使用 HybridSN 原论文、教师课件、本项目固定实验协议，以及教师指定参考仓库 `High_spectrum_BIT`。其中原论文是模型结构的最高依据；参考仓库只用于核对 PyTorch 维度顺序、3D→2D reshape 和 logits 写法，其 PCA20、patch11、50/50 划分和注意力模块均未进入本基线。

对 PyTorch 输入 `N×1×15×25×25`，所有卷积均采用 stride 1、padding 0。输出尺寸按 `out=floor((in+2p-k)/s)+1` 计算：

| 层 | 配置 | 输出 shape |
|---|---|---|
| 输入 | PCA15、patch25 | `N×1×15×25×25` |
| Conv3D-1 | `1→8`，kernel `(7,3,3)` + ReLU | `N×8×9×23×23` |
| Conv3D-2 | `8→16`，kernel `(5,3,3)` + ReLU | `N×16×5×21×21` |
| Conv3D-3 | `16→32`，kernel `(3,3,3)` + ReLU | `N×32×3×19×19` |
| 3D→2D | 合并通道与剩余光谱深度 `32×3` | `N×96×19×19` |
| Conv2D | `96→64`，kernel `3×3` + ReLU | `N×64×17×17` |
| Flatten | `64×17×17` | `N×18496` |
| 分类头 | `18496→256→128→9` | `N×9` |

两个隐藏全连接层均使用 ReLU，并各接 Dropout 0.4；模型不含池化、BatchNorm 或数据增强。唯一核心定义为 `src/models/HybridSN模型.py`，模型代码、数据预处理与训练控制保持分离。Pavia 输入与九分类头共有 `4,844,793` 个可训练参数；原论文表中的 `5,122,176` 对应 30 波段、16 类的 Indian Pines 配置，二者输入深度和类别数不同。

网络内部不添加 Softmax，直接输出 logits 供 PyTorch `CrossEntropyLoss` 使用；这是项目固定接口与原作者 Keras 最后一层表示形式之间的有意差异。除此之外，卷积核、通道数、激活、reshape、全连接宽度和 Dropout 均按原论文 Pavia 结构实现，并使用 Xavier/Glorot uniform 与零偏置对齐 Keras 默认初始化。

### 3.3 首个正式 baseline 结果

正式运行目录为 `experiments/pavia_university__hybridsn__seed1442__20260817-1251/`。固定训练集 12,832、测试集 29,944；训练总计 494.36 s，平均 4.931 s/epoch。最终测试结果如下：

| 指标 | 数值 |
|---|---:|
| OA | 99.9532% |
| AA | 99.8790% |
| Kappa | 0.999380 |
| 测试损失 | 0.004360 |
| 误分数 | 14 / 29,944 |
| 端到端测试推理 | 2.359 s，12,692 samples/s |

14 个错误主要分布在 Asphalt→Self-Blocking Bricks、Gravel→Trees、Trees→Asphalt/Meadows、Painted metal sheets→Shadows 和 Bitumen→Shadows。完整结果、图表、性能和空间重叠分析见 `docs/solution_report/HybridSN基线阶段实验报告草稿.md`。

### 3.4 研究架构分组对比

按照“降维—空间特征—分类器”研究架构，在 `fair24_6_70 + seed1442` 上完成 7 个传统方法，并合并 3 个相同协议的 HybridSN 结果。控制变量组覆盖 PCA15、LDA8、均匀15波段，LBP/Gabor/融合，以及 RBF-SVM/HistGradientBoosting。

纯 PCA15+SVM 的 Test OA 为 93.7016%；加入 LBP、Gabor 后分别达到 99.5124%、99.5692%，融合后达到 99.9365%（19 个错误）。相同融合特征上的 HistGradientBoosting 为 99.3755%。PCA15 HybridSN 为 99.9532%（14 个错误），比手工融合 SVM 高 0.0167 个百分点。完整 10 方法主表、逐类热力图、效率图、分类图和建设性改进见 `docs/solution_report/研究架构分组对比实验报告草稿.md`。

当前环境未安装 XGBoost，树提升组明确使用 sklearn HistGradientBoosting，二者没有被混写。九类标签互斥，HybridSN 使用 CrossEntropy/Softmax 语义；Sigmoid 不符合单标签多分类假设，未作为主实验组。
