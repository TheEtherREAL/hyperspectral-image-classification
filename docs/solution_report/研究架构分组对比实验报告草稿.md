# 研究架构分组对比实验报告草稿

## 1. 实验目的

本实验依据“高光谱数据—降维处理—空间特征提取与融合—分类方法”的研究架构，在统一数据划分和随机种子下设计控制变量实验，回答以下问题：

1. PCA、LDA 与直接波段选择对传统分类器的影响；
2. LBP、Gabor 及二者融合能否为纯光谱特征补充空间纹理信息；
3. 相同融合特征采用不同分类器时的精度与效率差异；
4. 传统手工光谱—空间方法与 HybridSN 深度模型之间的精度—成本权衡。

![研究架构分组设计](../../experiments/hsi_architecture_comparison__fair24_6_70__seed1442__20260817-1330/architecture_group_design.png)

## 2. 数据、样本与推理任务

Pavia University 数据是一个 `610×340×103` 的高光谱图像立方体，不是无序点云。前两个维度是图像空间坐标，第三个维度是同一像元在 103 个光谱波段上的观测值。其 Ground Truth 是 `610×340` 的标签图：0 表示未标注/背景位置，1–9 表示九种互斥地物类别，共有 42,776 个带标签像元。

传统模型以一个像元的降维光谱和局部纹理统计作为输入；HybridSN 以有标签像元为中心提取 `25×25` 空间 patch，模型输入为 `1×15×25×25`，一次输出中心像元的一个九分类结果。对多个像元重复推理并回填二维坐标后，才得到分类图。因此本课题最准确的名称是：

> **基于光谱—空间信息的逐像元高光谱图像分类。**

它在输出目标上与语义分割一样要为像元赋类，结果图也类似语义分割 mask；但当前 HybridSN 是 `patch → 中心像元标签`，不是 U-Net/FCN 式 `整图 → 整图` 的端到端密集语义分割网络。

## 3. 公平实验协议

- 数据划分：`fair24_6_70`；训练 10,265、验证 2,567、测试 29,944；
- split seed、模型 seed 和可复现随机过程统一为 1442；
- 标准化、PCA、LDA 和 Fisher 选带只使用训练中心像元拟合；
- 测试集不参与预处理拟合、超参数设置、checkpoint 选择或方法选择；
- 传统模型使用预先固定的超参数，验证集只用于报告和方法判断；
- HybridSN 复用相同划分和 seed1442 的 30 epoch 已完成结果，并由验证 OA 选择 checkpoint；
- 所有方法报告 OA、AA、Kappa、逐类准确率、错分数、训练与测试推理时间，并生成分类图。

传统空间特征的具体定义如下：

- LBP：在 PCA 前 3 个分量上计算半径 1、8 邻域 LBP，并在 `9×9` 邻域形成每分量 16 维归一化直方图；
- Gabor：在 PCA 前 3 个分量上使用 4 个方向（0°、45°、90°、135°）和 2 个频率（0.1、0.2），对响应幅值计算 `9×9` 局部均值与标准差；
- 融合：15 维 PCA 光谱、48 维 LBP 与 48 维 Gabor 串联为 111 维特征；
- 分类：RBF-SVM 使用 `C=16`、`gamma=scale`；HistGradientBoosting 使用 150 次迭代、31 个叶节点。

## 4. 控制变量分组

| 分组 | 固定条件 | 唯一主要变量 | 方法编号 |

| B：空间特征消融 | PCA15 + RBF-SVM | 无空间、LBP、Gabor、LBP+Gabor | R1、S1–S3 |
| C：分类器 | PCA15 + LBP + Gabor | RBF-SVM、HistGradientBoosting | S3、C1 |

## 6. 分组结果分析

### 6.1 降维/波段选择

固定 RBF-SVM 后，PCA15 的 Test OA 为 93.7016%，优于 LDA8 的 91.3438% 和均匀15波段的 90.3620%。相对 PCA15，LDA8 和均匀选带分别下降 2.3577、3.3396 个百分点。

LDA 的目标是寻找类别判别方向，但它最多只能输出“类别数−1”即 8 个分量，信息压缩更强；在当前固定 SVM 参数下没有超过 PCA。均匀选带保留了全谱覆盖，却没有根据信息量或类别判别力优化波段位置，因此性能最低。该结论只说明当前分量数、分类器与 seed1442 下 PCA 更合适，不代表 LDA 在所有数据集上必然更差。

### 6.2 空间特征消融

纯 PCA 光谱 SVM 的 Test OA 只有 93.7016%。加入 LBP、Gabor 和二者融合后，分别提高 5.811、5.868、6.235 个百分点。PCA15+LBP+Gabor+SVM 只错 19 个测试像元，说明局部纹理与方向响应对于区分光谱相近、空间结构不同的类别非常关键。

Gabor 单独组比 LBP 单独组高 0.0568 个百分点，训练和测试推理也更快；若需要轻量传统基线，可优先考虑 Gabor。融合组又比 Gabor 提高 0.3674 个百分点，证明 LBP 与 Gabor 在本协议下具有互补信息，但代价是维数由 63 增至 111、测试推理时间由 32.895 秒增至 52.539 秒。

### 6.3 分类器

在完全相同的 111 维融合特征上，RBF-SVM 的 Test OA 为 99.9365%，HistGradientBoosting 为 99.3755%，SVM 高 0.5610 个百分点；SVM 训练也更快。HistGB 的优势是测试推理仅 4.548 秒，明显快于 SVM 的 52.539 秒。因此，追求最高精度时选 SVM；对 CPU 低延迟更敏感时，可进一步调优树提升模型。

### 6.4 传统方法与 HybridSN

PCA15 HybridSN 取得最高 Validation OA（100%）与最高 Test OA（99.9532%），按预设验证集规则应选 D1。它相对纯 PCA 光谱 SVM 提高 6.2517 个百分点，但只比手工融合 SVM 高 0.0167 个百分点，即少错 5 个测试像元。

这表明当前数据协议下，LBP/Gabor 手工空间特征已经非常有竞争力；HybridSN 的优势主要体现在端到端学习和 GPU 批量推理，而不是大幅度的 OA 领先。另一方面，HybridSN 约有 484 万可训练参数，训练时间和硬件需求高于传统方法。时间结果来自不同硬件路径（传统模型 CPU、HybridSN GPU），只能反映本机工程成本，不能作为严格算法复杂度对比。

## 8. Softmax 与 Sigmoid 的选择

每个 PaviaU 有标签像元只能属于九类中的一个类别，因此是单标签、多类别、互斥分类。HybridSN 输出九维 logits，使用 `CrossEntropyLoss`；该损失在数值上组合了 LogSoftmax 与负对数似然，推理时对 logits 取 argmax 即可。

Sigmoid 会把九个类别当作九个相互独立的二分类目标，适合一个样本可同时属于多个类别的多标签问题，不符合本数据标签定义。为了保证实验科学性，本报告不设置“Sigmoid 主实验组”。如果为了教学演示强行加入，只能作为不匹配任务假设的负面对照，不能与 Softmax 结果等价比较。

## 9. 有效性威胁

随机像元划分存在很强的空间相关性。对传统特征使用的 `9×9` 窗口，99.6126% 的测试窗口至少包含一个训练中心，99.5158% 至少包含一个同类训练中心，每个测试窗口包含训练中心的中位数为 14。HybridSN 的 `25×25` patch 重叠更严重。因此，99% 以上的结果适合课程固定协议内对比，但不能解释为跨区域、跨城市或真正未知场景的泛化能力。

此外，本轮所有实验按要求统一 seed1442。单 seed 能保证流程一致，却不能估计随机波动；微小差异（如 HybridSN 与融合 SVM 的 0.0167 个百分点）不能直接视为稳定优势。

## 10. 建设性改进方向

1. **优先增加空间块划分。** 按连通区域或空间块划分 train/validation/test，并与随机像元结果并列报告，这是当前最重要的可信度改进。
2. **补做真正的 XGBoost。** 安装 `xgboost`，固定同一 111 维融合特征和 seed1442，增加 XGBoost，而不是把 HistGB 更名为 XGBoost。
3. **仅在验证集调参。** 对 SVM 的 C/gamma、LBP pooling 窗口、Gabor 频率/方向做小型网格，冻结规则后只评估一次 test。
4. **增加稳健性实验。** 最终结论采用同一批 3–5 个种子，报告 OA/AA/Kappa 均值±标准差；seed1442 保留为主复现实验。
5. **轻量化 HybridSN。** 比较更小 patch、通道裁剪、深度可分离卷积，同时报告参数量、显存和吞吐率。
6. **结构优化。** 在公平基线上逐项加入 BatchNorm、残差连接、光谱/空间注意力，每次只改变一个模块并做消融。
7. **针对难类改进。** 从逐类热力图和混淆矩阵定位易混类别，再决定采用判别式选带、类权重、边界增强或更强空间上下文。
