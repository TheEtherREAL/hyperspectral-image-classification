# 三大数据集分布插图

直观展现 **Pavia University / Indian Pines / Salinas** 三大高光谱数据集的空间结构、类别样本分布与光谱分布，产出可直接插入实验报告的 PNG 插图。

## 运行

```bash
cd 实验交付
python 数据集分布插图/生成三大数据集分布插图.py
```

脚本自动复用工程内的数据读取模块（`src/datasets/数据读取.py`、`数据集注册.py`），从 `data/raw/*.mat` 读取三套数据集，无需重复造轮子。

## 输出

图输出至本目录 `figures/` 子目录：

| 文件 | 内容 |
| --- | --- |
| `fig1_三大数据集_空间结构.png` | 3 行 × 2 列：假彩色合成图（波段 60/30/10）+ 地物真值图 |
| `fig2_三大数据集_类别分布.png` | 3 面板水平条形图：各类别有标签像元数（类别不平衡） |
| `fig3_三大数据集_光谱分布.png` | 3 面板折线图：有标签像元平均光谱（均值 ± 标准差） |

同时控制台打印三套数据集的逐类像元数汇总，便于核对报告中的样本量表。

## 约定

- 假彩色合成波段沿用工程既有口径 `[60, 30, 10]`（与 `notebooks/01_数据读取划分与预处理.ipynb` 一致），按 2%~98% 百分位线性拉伸提升对比度。
- 地物真值配色沿用工程既有的 `nipy_spectral`。
- 每套数据集使用统一强调色（Pavia 蓝 / Indian Pines 绿 / Salinas 橙），三幅图可相互对照。
