# Pavia 数据预处理配置说明

## 1. 唯一日常入口

日常只编辑：

```text
configs/数据预处理/Pavia数据预处理.yaml
```

阶段 2 曾使用的七份路线预设已原样移入：

```text
归档/阶段2历史配置/数据预处理多文件预设/
```

归档配置只用于追溯，不作为日常入口。已有冻结状态仍保存在 `data/processed/pavia_university/`，没有移动或覆盖。

## 2. 三个主要选择字段

### 2.1 数据划分

```yaml
dataset:
  split_protocol: fair24_6_70
  split_seed: 345
```

- `paper30`：30% 训练、70% 测试，没有验证集，用于论文兼容复现；
- `fair24_6_70`：24% 训练、6% 验证、70% 测试，用于调参与公平比较；
- `split_seed` 固定为 345，不作为普通调参项。

### 2.2 光谱处理

```yaml
spectral_preprocessing:
  standardization: standard
  reducer: pca
  pca:
    n_components: 15
    whiten: false
  lda:
    n_components: 8
```

只修改 `reducer`：

- `pca`：选择 PCA 参数块，默认将 103 波段映射为 15 个主成分；
- `lda`：选择 LDA 参数块，默认将 103 波段映射为 8 个判别分量；
- `none`：不降维，保留标准化后的 103 波段。

Pavia 有 9 类，因此 LDA 的 `n_components` 只能取 1–8。LDA 仅使用训练光谱和训练标签拟合。

### 2.3 空间表示

```yaml
spatial_preprocessing:
  representation: patch
  patch_size: 25
```

- `patch`：动态提取邻域，供 HybridSN、3D-CNN 等模型使用；
- `pixel`：只返回中心像元特征，供 SVM、XGBoost 或 MLP 使用；
- `patch_size` 仅在 patch 路线生效，必须是正奇数。

## 3. 常用路线如何配置

| 用途 | `split_protocol` | `reducer` | `representation` |
|---|---|---|---|
| 日常公平调参、PCA-patch | `fair24_6_70` | `pca` | `patch` |
| LDA-patch 对照 | `fair24_6_70` | `lda` | `patch` |
| PCA + 传统分类器 | `fair24_6_70` | `pca` | `pixel` |
| LDA + 传统分类器 | `fair24_6_70` | `lda` | `pixel` |
| 原始 103 波段对照 | `fair24_6_70` | `none` | `pixel` |
| HybridSN 论文兼容复现 | `paper30` | `pca` | `patch` |
| paper30 下的 LDA 对照 | `paper30` | `lda` | `patch` |

## 4. 配置与冻结状态的关系

一个 YAML 可以选择多条路线，但每条统计预处理路线仍对应独立的冻结状态目录，例如：

```text
fair24_6_70__seed345__standard_pca15_patch25
fair24_6_70__seed345__standard_lda8_patch25
paper30__seed345__standard_pca15_patch25
```

原因是不同划分或不同算法会拟合出不同的标准化、PCA/LDA 参数，不能混用。

只修改以下运行参数不需要新状态：

- `dataloader.batch_size`；
- `dataloader.loader_seed`；
- `dataloader.num_workers`；
- `dataloader.pin_memory`。

切换 split、reducer、降维维数、标准化、pixel/patch 或 patch 大小时，需要对应的新状态。程序不会自动拟合；若状态尚不存在，应先检查配置，再使用受控生成脚本，且不要覆盖已有目录。

## 5. 检查与运行

检查当前选择及对应状态是否存在：

```powershell
.\.venv\Scripts\python.exe scripts\检查配置.py `
  --config "configs\数据预处理\Pavia数据预处理.yaml"
```

逐步只读运行：

```powershell
.\.venv\Scripts\python.exe scripts\运行数据预处理.py
```

若检查显示 `冻结状态存在=False`，确认这是一个确实需要的新实验路线后再生成：

```powershell
.\.venv\Scripts\python.exe scripts\生成预处理状态.py `
  --config "configs\数据预处理\Pavia数据预处理.yaml"
```

生成器默认拒绝覆盖。不要随意使用 `--overwrite`。

## 6. 模型阶段参数

学习率、dropout、epoch、优化器和模型结构不属于本文件。它们应放在 `configs/模型训练/` 中，并在正式实验时将使用的完整配置复制到实验结果目录，保证结果可追溯。
